# Bleach Fan Site

A fan site dedicated to the anime and manga *Bleach*.

## Technologies
- HTML
- CSS / Tailwind CSS
- JavaScript

## Project Structure
- `docs/` — website files for GitHub Pages
- `images/` — character images
- `style/` — CSS files
- `scripts/` — JavaScript files

## Local Setup
Open `index.html` in a browser.
